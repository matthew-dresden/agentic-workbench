# E7-F2: Dynamic completers (six hidden subcommands + mid-token splitter)

## Status: in-queue

## Description

Implements the six dynamic completers from spec Section 11.3 plus the
mid-token splitter from Section 11.5. Each completer is a hidden
`mpm __complete_<name>` subcommand registered in `src/mpm_cli/cli.py`.
The shell preamble (E7-F1-S1-T2) shells out to these subcommands and
hands stdout to the shell as completion candidates.

Completers shipped:

1. `__complete_catalog_entries` -- reads the resolved manifest repo
   (clone + cache); enumerates `repo-specs/**/*-marketplace.xml`;
   emits one `<catalog-metadata><name>` per line.
2. `__complete_source_names_in_mpm` -- reads
   `${MPM_MPM_FILE:-./.mpm}`; emits one normalized source name
   per line (parsed from `MPM_SOURCE_<name>_URL` keys). Normalization
   is one-way and lossy; only the normalized form is emitted.
3. `__complete_names_in_lockfile` -- reads `${MPM_LOCK_FILE}`
   (resolved per Section 4.7); emits top-level source names + every
   transitive `<include>` path + every `<project>` URL, one per line.
4. `__complete_catalog_versions` -- reads `git ls-remote --tags + --heads`
   of the manifest repo; emits one tag + one branch per line, deduped.
   PEP 440 filter: tags whose last path component is not a valid
   `packaging.version.Version` are excluded.
5. `__complete_project_versions <repo-url>` -- same shape as completer
   4 but for a specific `<project>` repo URL. Used by the mid-token
   splitter when `mpm add foo@<TAB>` is detected.
6. `__complete_cached_catalogs` -- reads `${MPM_CACHE_DIR}/catalogs/*`
   index; emits one `<url>@<ref>` per line for every manifest repo the
   operator has touched.

The mid-token splitter (Section 11.5) lives in the shell preamble (a
shell function that detects the `@` separator -- splitting on the LAST
`@` per Section 4.0 -- and routes to `__complete_project_versions` or
`__complete_catalog_entries` accordingly). The Python side ships a
helper `src/mpm_cli/completions/midtoken.py` that performs the
entry-name -> repo-url lookup the shell helper calls into via
`mpm __complete_project_versions`.

Spec source: spec Section 11.3 (dynamic completers table) and 11.5
(mid-token splitting).
